## 6. Remonter l'environnement sur un autre PC

```bash
git clone https://gudr-perso@github.com/gudr-perso/Anonymator.git
cd Anonymator          # `main` contient tout, plus besoin de changer de branche
python -m venv .venv
./.venv/Scripts/python -m pip install -r requirements.txt
```

⚠️ **Vérifier OpenCV juste après**, la seule étape non automatisable :

```bash
./.venv/Scripts/python -m pip list | grep -i opencv
```

Il ne doit apparaître **que** `opencv-python-headless`. Si `opencv-python` est là aussi,
`rapidocr` l'a tiré en dépendance — corriger :

```bash
./.venv/Scripts/python -m pip uninstall -y opencv_python
./.venv/Scripts/python -m pip install --force-reinstall --no-deps opencv-python-headless
```

Les deux variantes écrivent le **même dossier `cv2`** et ne cohabitent pas : désinstaller
l'une efface les fichiers de l'autre. La complète embarque ses propres plugins Qt, qui
entrent en conflit avec PySide6 sous PyInstaller.

Puis :

```bash
./.venv/Scripts/python -m pytest -q          # 818 verts attendus
./.venv/Scripts/python -m anonymator         # l'application se lance
```

## 7. Pièges rencontrés, à ne pas redécouvrir

1. **Ne pas se fier aux comptes de tests absolus** des plans : ils dérivent selon la
   branche et les paquets installés. Raisonner en **écarts**. Le compte ne baisse jamais.
2. **Une autre session Claude travaille sur ce dépôt en parallèle** : `main` a bougé en
   cours de session le 2026-09-23. `git fetch && git log origin/main` avant de supposer.
3. **`Referential()` n'existe pas** — utiliser `Referential.load_default()`.
4. **`set_overlays(entity_rects, manual_rects, unconfirmed_rects)`** : les manuelles
   **avant** les non confirmées. Inverser ne lève aucune erreur, ça affiche seulement le
   mauvais style.
5. **`isVisible()` d'un widget enfant est faux** tant que la fenêtre parente n'est pas
   affichée : appeler `.show()` dans les tests d'overlay.
6. **Messages de commit** : passer par `git commit -F <fichier>`, les guillemets dans un
   `-m` cassent le passage d'argument sous PowerShell.
7. **`sed` avec `#` comme délimiteur** sur un motif contenant `#` corrompt le fichier en
   silence. Récupération : `git checkout -- <fichier>`.
