## 5. Remonter l'environnement sur un autre PC

```bash
git clone https://gudr-perso@github.com/gudr-perso/Anonymator.git
cd Anonymator
git checkout feat/anonymisation-images
python -m venv .venv
./.venv/Scripts/python -m pip install -r requirements.txt
```

Puis, **et c'est indispensable pour les phases 2 et suivantes**, installer l'OCR —
qui n'est pas encore dans `requirements.txt` (il y entre à la tâche 14) :

```bash
./.venv/Scripts/python -m pip install rapidocr
./.venv/Scripts/python -m pip uninstall -y opencv_python
./.venv/Scripts/python -m pip install --force-reinstall --no-deps opencv-python-headless
./.venv/Scripts/python -m pip list | grep -i opencv    # doit ne montrer QUE le headless
```

⚠️ **Les trois commandes, dans cet ordre.** `rapidocr` réclame `opencv_python`, la
variante avec plugins Qt, qui entre en conflit avec PySide6 sous PyInstaller. Demander
le headless en même temps ne suffit pas : pip installe **les deux**. Et comme elles
écrivent le **même dossier `cv2`**, désinstaller la complète efface aussi le headless —
d'où la réinstallation forcée. Constaté en direct le 2026-09-23.

Vérifications :

```bash
./.venv/Scripts/python -m pytest -q          # doit être entièrement vert
./.venv/Scripts/python -m anonymator         # l'application se lance
```

## 6. Pièges propres à ce chantier

1. **Ne pas se fier aux nombres absolus de tests du plan.** Ils ont été écrits sur une
   base à 721, dépassée depuis. **Les deltas par tâche restent justes** ; relever son
   point de départ par un `pytest -q` et raisonner en écarts. Règle intangible : le
   compte ne baisse jamais.
2. **`Referential()` n'existe pas** — le constructeur exige des entrées. Utiliser
   `Referential.load_default()`. Le plan a été corrigé, mais le réflexe est à garder.
3. **Ordre des paramètres de `set_overlays`** : `(entity_rects, manual_rects,
   unconfirmed_rects)`. Les manuels **avant** les non confirmés. Inverser ne lève
   aucune erreur : les overlays s'affichent juste avec le mauvais style.
4. **`sed` et le délimiteur `#`** : un motif contenant `#` avec `#` comme délimiteur
   corrompt le fichier en silence. Récupération : `git checkout -- <fichier>`.
5. **Le conflit opencv ne se voit qu'au lancement de l'exe**, jamais en test — d'où
   l'étape de validation manuelle de la tâche 18.
